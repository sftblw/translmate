# 0.1.0 · 2026-11-18

Firefox용 확장과 검토용 소스는 고정된 잠금 파일로 빌드한다.

- 새 공급자에 Responses API를 우선 적용하고, 기존 Chat Completions 설정을 계속 사용할 수 있게 했다.
- 자동 추출로 본문을 식별하기 어려우면 선택한 모델이 제한된 발췌문과 후보 ID로 읽기 영역을 고른다.
- 진행 표시를 문단 바깥으로 옮겼다. 원문 보기 상태를 보존하고, 번역으로 줄바꿈이 바뀌거나 내부 스크롤 영역이 이동하면 남은 작업의 우선순위를 다시 계산한다.
- 컨텍스트 예산의 80%에서 오래된 대화를 LLM으로 요약한다. 시스템 메시지와 최근 대화 두 쌍 및 현재 턴의 도구 교환을 보존한다.
- 작은 도구 모음용 정적 번역 아이콘을 적용했다. 실제 동작에 연결되지 않던 예전 배치 번역 옵션을 설정 화면에서 제거했다.
- AI SDK 7, WXT 0.21, Vitest 5로 갱신했다. Oxlint, Prettier와 Svelte 타입 검사를 추가하고 사용되지 않는 배치 번역 코드를 정리했다.
- Firefox 내장 데이터 전송 동의를 사용할 수 있도록 최소 버전을 데스크톱 140, Android 142로 지정했다.

- 설정 탭에서 번역을 시작하면 요청한 웹페이지를 대상으로 삼고, 페이지가 교체되면 이전 문서에 연결된 작업을 취소한다. 삭제한 공급자의 키가 예전 설정 필드에 남거나 다른 엔드포인트로 요청이 전송되는 경로를 제거했다.
- 갱신 때마다 전체 DOM을 복제하던 미사용 파서를 제거했다.

- 새 설치의 모델, 키, 엔드포인트를 비우고 대상 언어는 브라우저 설정을 따른다. 기존에 저장한 공급자와 언어는 유지한다.
- 중복 테스트와 문구 검사를 정리해 기본 검사를 231개에서 핵심 동작 및 실제 회귀 54개로 줄였다. 모델 호출이 필요한 실서비스 테스트 하나는 명시적으로 실행한다.
- README를 사용자 설정·번역·재현 빌드 순서로 개편하고 저장소 루트 AGENTS.md에 작업 규칙을 모았다.

## 검증

Firefox 160의 임시 프로필에서 확인했다. vLLM과 oMLX 모두 Responses 및 Chat Completions로 실제 도구 호출과 DOM 반영을 수행했다.

| 대상 | 관찰 결과 |
| --- | --- |
| IANA Example Domains | vLLM Responses 6/6 완료. 원문 보기와 저장 번역 재표시 확인. oMLX Chat Completions로 본문 번역 확인. |
| Python `__future__` 문서 | vLLM Chat Completions 전체 문서 모드 51/51 완료. 큰 폭으로 스크롤한 뒤 마지막 문단의 한국어 표시와 원문 복원 확인. |
| W3C Tim Berners-Lee 소개 | oMLX Chat Completions로 소개 문단이 실제로 바뀌는 것을 확인. 캡처 시점에는 25개 중 6개 적용. |
| 일반 div로 작성한 로컬 기사 | oMLX로 두 프로토콜 각각 본문 3/3 적용. 인라인 강조를 보존했고 추천 영역의 원문을 유지. |
| 대화 압축 | oMLX가 오래된 대화를 요약한 뒤 다음 실제 요청에서 요약, 시스템 메시지, 최근 대화 두 쌍과 진행 중인 턴을 확인. |
| 설정 저장 | Firefox 옵션 화면에서 공급자 추가, 모델 목록 조회, 기본 모델 지정, 새로고침 후 복원 및 삭제 후 키 제거 확인. |

Windows와 Ubuntu에서 소스 ZIP의 잠금 파일로 빌드했다. 확장 내부 파일 13개의 내용이 일치했다. 런타임 의존성 감사 결과는 0건이다. 개발 의존성에는 패치 버전이 아직 없는 picomatch 경고가 남아 있다. web-ext lint는 오류 0건으로, Svelte와 Zod에 관한 정적 경고는 검토자 문서에 기록했다.

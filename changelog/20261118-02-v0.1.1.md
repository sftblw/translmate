# 0.1.1 · 2026-11-18

- 공개판은 `translmate@sftblw.moe`를 사용한다. 기존 비공개판 사용자는 공개판을 새로 설치하고 공급자를 다시 설정해야 한다.

- 공급자 설정에 HTTP 평문 전송과 번역 대상 본문의 범위를 표시한다. LAN의 IP와 호스트 이름을 직접 사용할 수 있다. 모델 목록과 추론 요청은 설정한 서버의 최종 주소에 보낸다.
- GitHub 홈페이지와 지원 링크, MIT 또는 Apache-2.0 라이선스, 계정 없이 로컬 모델을 쓰는 AMO 심사 절차를 추가했다.

## 검증

Firefox 160에서 vLLM Responses로 IANA 기사 6개 단위를 모두 적용하고 마지막 문단의 한국어 표시와 원문 복원을 확인했다. oMLX Chat Completions로 일반 div 기사 3개 단위를 모두 적용했다. 두 서버 모두 LAN HTTP에 직접 연결했다.

기본 검사 54개가 통과했다. Ubuntu에서 소스 ZIP으로 재현한 확장 내부 파일 18개가 Windows 빌드와 일치했다. web-ext lint는 오류 0개, 경고 2개였다.

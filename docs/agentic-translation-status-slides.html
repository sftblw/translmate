Translmate status report

에이전틱 번역은 큰 줄기는 구현됨. 포커스 연결은 방금 보강됨.

현재 구현은 배치 번역이 아니라, background의 page agent가 문서 상태를 들고 모델 도구 호출로 작업을 진행하는 구조입니다. 의도와 맞는 부분이 많지만, 실제 브라우저에서 provider stream이 주는 tool payload 형태는 추가 확인이 필요합니다.

판정: 구조는 의도 방향

Current runtime

현재 번역 루프는 content, background actor, tool runner로 분리됩니다.

1. 사용자가 시작popup/content가 pageAgent/startTranslation을 보냅니다.
2. content 수집현재 viewport와 near viewport unit을 추출합니다.
3. actor 상태화background가 unit을 document resource로 저장합니다.
4. 모델 도구 호출get_next_units, submit_translations로 진행합니다.
5. 검증 후 적용background 검증 뒤 content가 DOM patch를 적용합니다.

State ownership

의도했던 “문서 상태와 대화 이력 분리”는 코드에 들어가 있습니다.

Document resource

background PageAgentActor가 documentById로 unit 상태, 원문, 번역문, lease를 관리합니다.

구현됨

History surface

사용자 메시지, assistant text, tool call/result, validation 이벤트가 별도 history/event로 쌓입니다.

구현됨

Scheduler/lease

get_next_units는 pending unit을 priority 순으로 lease하고 turn이 끝나면 남은 lease를 해제합니다.

구현됨

Tool loop

번역 결과는 assistant final text가 아니라 도구 호출로만 들어옵니다.

Model

선택: mark_intent 필수: get_next_units 선택: get_unit_context 필수: submit_translations

Runtime guardrail

lease 없는 번역은 정상 경로가 아님 placeholder 보존 검증 final text 번역 파싱 금지 미완료면 continuation enqueue

Content

검증된 번역만 DOM patch stale session 차단 progress overlay 표시

Highlight focus

하이라이트 포커스는 tool payload의 unit id를 따라 움직이도록 보강했습니다.

Unit A: 대기 중인 문단입니다.
get_next_units: leased Unit BUnit B: 현재 도구 호출이 대상으로 잡은 문단입니다.
Unit C: 이후 번역될 문단입니다.

현재 연결 방식

ToolLoopPageAgentRunner가 tool input/output에서 unitId들을 추출해 focusedUnitIds로 stream chunk에 싣습니다. content는 이를 받아 focusChunks()로 active class를 이동합니다.

요구사항 반영

What matches your intent

의도와 맞는 부분

에이전트가 작업을 고름

runtime이 prompt에 모든 batch를 밀어넣는 형태가 아니라, 모델이 get_next_units로 다음 작업을 가져가는 구조입니다.

번역 적용 권한은 runtime/content

모델은 submit_translations로 제안만 하고, background 검증과 content patch를 거칩니다.

진행 상황이 페이지에 보임

stream chunk와 session snapshot이 content overlay로 전달됩니다.

viewport 변화가 세션에 이어짐

visibleUnitsChanged가 기존 actor에 enqueue되어 새 영역을 같은 page-agent session에 붙입니다.

Gaps and risks

아직 확인이 필요한 부분

Provider stream shape

테스트 stream에서는 tool output이 보존됩니다. 실제 AI SDK provider가 fullStream에 같은 구조로 input/output을 주는지는 live 확인이 필요합니다.

실기 확인 필요

압축/요약

문서와 history 분리는 됐지만, 긴 history를 제품 수준으로 compact하는 구현은 아직 별도 단계입니다.

부분 구현

Focus granularity

현재 focus는 unit 단위입니다. wrapper 또는 inline segment 단위까지 미세하게 따라가는 UI는 아닙니다.

의도 확인 필요

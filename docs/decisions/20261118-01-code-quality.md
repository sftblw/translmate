# 코드와 기록 관리

상태 `implemented`

테스트는 사용자 동작이나 핵심 상태 변화를 검증한다. 경계 조건은 실제 장애가 확인되었을 때 회귀 테스트로 남긴다. 화면 문구나 프롬프트의 특정 표현은 그 자체가 동작 계약인 경우에만 검증한다.

이름과 제어 흐름으로 의도를 드러낸다. 외부 제약 때문에 코드만 읽어서는 근거를 파악할 수 없을 때만 짧은 주석을 쓴다. 일반 주석의 필요성은 리뷰에서 판단한다.

결정은 이 디렉터리의 20개 제한과 전체 교체 규칙을 따른다. 사용자에게 영향을 주는 변경과 검증 범위는 루트 changelog.md와 날짜별 버전 문서에 기록한다. 소스와 문서는 UTF-8로 저장한다.

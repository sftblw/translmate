# 공급자별 API 프로토콜

상태 `implemented`

새 공급자는 Responses API를 우선한다. Anthropic 호환 프리셋은 Chat Completions를 선택한다. 프로토콜이 저장되어 있지 않은 기존 공급자는 이전 호출 방식인 Chat Completions로 읽는다. 사용자가 공급자를 편집하면 양쪽 중 하나를 명시적으로 저장할 수 있다.

본문 선택, 번역 도구 호출, 대화 요약은 같은 공급자와 모델을 사용한다. 실패한 생성 요청을 다른 프로토콜로 자동 재전송하면 중복 호출이나 중복 과금이 발생할 수 있어 전환은 설정에서 수행한다.

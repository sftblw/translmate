# 번역 대화의 압축

상태 `implemented`

입력 컨텍스트 예산의 80%에 도달하면 현재 공급자의 LLM으로 기존 요약과 오래된 대화를 요약한다. 시스템 메시지, 최근에 완료된 사용자·어시스턴트 대화 두 쌍과 진행 중인 턴은 원형으로 유지한다. 턴 안에서 도구를 여러 번 호출할 때도 압축을 검사한다.

모델이 보고한 토큰 사용량과 로컬 추정치를 사용한다. 기본 예산은 32,000토큰이며 사용자가 선택한 모델에 맞게 바꿀 수 있다. 유효한 요약을 얻은 뒤에만 이력을 교체한다. 문단의 원문·번역문·작업 상태는 별도로 유지한다.

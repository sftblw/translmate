# 읽기 영역과 문서 수명

상태 `implemented`

번역 시작 시 문서 구조에서 본문을 먼저 찾는다. 식별하기 어려운 경우 콘텐츠 스크립트는 후보 영역의 제한된 발췌문과 임시 ID를 만든다. 백그라운드에서 선택된 모델이 ID를 고르면 콘텐츠 스크립트가 해당 DOM 요소를 세션에 연결한다. 모델에게 임의의 선택자나 스크립트 실행 권한을 주지 않는다. 사용자가 영역을 직접 지정할 수도 있다.

원문, 번역문, 현재 보기 상태를 별도로 관리한다. 번역 진행 표시는 본문의 줄바꿈에 영향을 주지 않는 위치에 놓는다. 번역 적용이나 스크롤로 읽기 범위가 바뀌면 새 범위에 우선순위를 준다.

최상위 문서가 교체되면 이전 작업을 취소한다. 새 문서는 새 대화와 문단 ID로 시작한다. 문서 안에서 위치만 이동하는 경우에는 진행 중인 작업을 유지한다.

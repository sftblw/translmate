# 새 설치의 공급자와 번역 언어

상태 `implemented`

새 설치에서 엔드포인트, 모델, API 키는 비워 두고 브라우저의 언어 설정을 초기 번역 언어로 사용한다. 공급자 추가 화면은 빈 Custom 양식에서 시작한다. 사용자가 프리셋을 고르면 해당 서비스 주소를 채운다. 실제 연결은 사용자가 설정한 공급자로 수행한다.

기존 설치에서 지정한 공급자, 모델, 키와 번역 언어를 보존한다. 공급자 목록 도입 전 형식은 저장된 엔드포인트와 모델이 모두 있을 때 마이그레이션한다. 실서비스 검증 주소와 모델은 실행 환경에서 주입한다.

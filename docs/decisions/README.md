# 결정 기록

새 결정은 `YYYYMMDD-NN-name.md`에 작성하고 상태를 `decided`로 기록한다. 구현과 검증을 마치면 `implemented`로 변경한다. 허용하는 세 번째 상태는 `superseeded`이다.

결정의 일부가 달라져도 계속 적용할 내용까지 포함해 새 문서를 완전히 작성한다. 이전 문서 전체를 `superseeded`로 바꾸고 후속 문서를 연결한다.

날짜가 붙은 개별 결정 파일은 최대 20개다. 21번째를 추가하기 전에 병합할 항목을 [압축 대기 목록](pending-compaction.md)에 기록한다. 유효한 결정끼리 병합할 때도 후속 문서에 전체 정책을 작성한다. 대체된 기록의 날짜, 핵심 근거와 후속 결정을 [압축 기록](compacted.md)에 옮긴 뒤 해당 개별 파일과 대기 항목을 제거한다. 세 관리 문서는 개수에서 제외한다.
